# Kurs Embedded C - Indeks

## 📚 Opis kursu
Kompleksowy kurs programowania w języku C dla systemów wbudowanych. Kurs obejmuje wszystkie aspekty programowania embedded - od podstaw języka C przez programowanie niskopoziomowe po zaawansowane techniki optymalizacji i debugowania.

## 🎯 Dla kogo jest ten kurs?
- Studenci elektroniki i automatyki
- Początkujący programiści systemów wbudowanych
- Programiści chcący przejść z wyższego poziomu do embedded
- Inżynierowie pracujący z mikrokontrolerami

## 🛠️ Narzędzia wymagane
- Kompilator GCC ARM lub AVR-GCC
- IDE: STM32CubeIDE, Keil, IAR lub VSCode z rozszerzeniami
- Debugger: GDB, OpenOCD
- Mikrokontroler do testów (Arduino, STM32, ESP32, itp.)
